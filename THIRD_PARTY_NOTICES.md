# 第三方数据与声明

本站与任何拼豆品牌均无关联。品牌名称仅用于说明色号对应关系。屏幕色仅供参考，以实物为准。

## 色卡数据来源

| 色系 | 来源 | 说明 |
|---|---|---|
| MARD / COCO / 漫漫 / 盼盼 / 咪小窝 | Zippland/perler-beads（AGPL-3.0）整理的 291 色映射 | 社区参考色卡，非品牌官方数据 |
| Artkal S | Artkal 官方 S 系列 RGB 色卡 PDF（2024） | S41/S42/S63 金属色官方无 RGB，S94/S155 官方值与其他色号重复，这 5 色改用 maxcleme/beadcolors 社区值 |
| Artkal C / M | Artkal 官方 RGB 色卡，经 HansBug/pindou-color-data 整理（MIT） | C 系列 9 个透明色、M 系列 MH1 无可靠色值未收录 |
| Perler | 103 色来自 maxcleme/beadcolors 社区实测值（MIT）；28 色为 perler.com 官方商品色块图取样（2026-11-12） | 取样部分标为估算；色号为官方商品 SKU |
| Hama Midi | maxcleme/beadcolors 社区实测值（MIT），92 色 | 社区参考，非品牌官方数据（Hama 官方未公布 RGB） |
| Nabbi | maxcleme/beadcolors 社区实测值（MIT），30 色 | 社区参考，非品牌官方数据 |
